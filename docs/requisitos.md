# Requisitos del Sistema - Fitzone

## Requisitos Funcionales

### Módulo de Miembros
- RF-01: El sistema debe permitir registrar nuevos miembros con datos personales.
- RF-02: El sistema debe permitir consultar, modificar y eliminar miembros.
- RF-03: El sistema debe registrar el historial de asistencia de cada miembro.

### Módulo de Membresías y Pagos
- RF-04: El sistema debe gestionar los tipos de membresía disponibles.
- RF-05: El sistema debe registrar y controlar los pagos de los miembros.
- RF-06: El sistema debe notificar sobre membresías próximas a vencer.

### Módulo de Entrenamiento
- RF-07: El sistema debe permitir crear rutinas de entrenamiento personalizadas.
- RF-08: El sistema debe asignar rutinas a miembros específicos.
- RF-09: El sistema debe registrar el progreso de cada miembro.

### Módulo de Equipos
- RF-10: El sistema debe llevar el inventario del equipamiento del gimnasio.
- RF-11: El sistema debe registrar el mantenimiento de los equipos.

### Módulo de Reportes
- RF-12: El sistema debe generar reportes de asistencia.
- RF-13: El sistema debe generar reportes de ingresos por período.

## Requisitos No Funcionales

- RNF-01: La interfaz debe ser intuitiva y fácil de usar.
- RNF-02: El sistema debe ser accesible desde dispositivos de escritorio.
- RNF-03: Los datos deben almacenarse de forma segura.
- RNF-04: El sistema debe responder en menos de 2 segundos para operaciones comunes.
